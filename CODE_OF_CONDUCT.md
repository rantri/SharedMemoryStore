# Code of Conduct

SharedMemoryStore is a technical project for shared-memory package work. Project
discussion should stay focused, specific, and respectful.

## Expected Behavior

- Treat other contributors and users with professional respect.
- Explain technical disagreements with concrete evidence from code, tests,
  contracts, benchmarks, or documentation.
- Keep issue and pull request discussion relevant to the project.
- Protect private information, credentials, payload data, and vulnerability
  details.
- Make space for maintainers to ask for reproducible evidence before accepting
  behavior or performance claims.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private contact information, secrets, exploit details, or
  proprietary payloads.
- Repeatedly derailing issues or pull requests away from the project topic.
- Misrepresenting package support, platform validation, security status, or
  release readiness.

## Enforcement

Maintainers own enforcement for this repository. They may edit, hide, or remove
comments; close issues; request changes; block participation; or escalate to the
hosting platform when needed.

For ordinary support and project questions, use [SUPPORT.md](SUPPORT.md). For
security-sensitive reports, use [SECURITY.md](SECURITY.md) and avoid public
details.
